# Uncertainty budget

Each worksheet revision stores a versioned list of uncertainty sources with type A/B, stated uncertainty, distribution, divisor, sensitivity coefficient and degrees of freedom. Supported mock distributions map to explicit divisors; production values must come from approved method configuration.

The calculation returns standard uncertainties, signed contributions, combined standard uncertainty, effective degrees of freedom, coverage factor and expanded uncertainty. Missing, expired, out-of-range or wrong-branch standards block calculation. Unresolved external legacy links remain visible warnings. Budgets and results are internal evidence and are excluded from customer API projections unless an approved certificate field explicitly presents the final uncertainty.
