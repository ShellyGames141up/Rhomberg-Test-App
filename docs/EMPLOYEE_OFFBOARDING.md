# Employee Offboarding

Use `Archive Employee`; do not delete an identity that owns historical records.

The Administrator records the last working date, reason, replacement employee where required and a plan for customers, open RFQs and order responsibilities. The service checks active work before continuing. Archiving disables login and future notifications while preserving the employee profile, historical ownership, certificates, workflow events and immutable audit attribution.

If active responsibilities exist, a replacement is mandatory. Reassignment is a separate audited operation and must respect branch, company and workflow scope. Historical events continue to name the original actor.

Production offboarding must also revoke identity-provider sessions, refresh tokens and device registrations; remove group memberships; disable external integrations; transfer private files under approved policy; and retain an IT service-ticket reference. Permanent deletion is not an ordinary application action.
