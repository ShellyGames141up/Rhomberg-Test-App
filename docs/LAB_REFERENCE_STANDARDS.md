# Laboratory reference standards

The committed register contains fabricated standards only. Each record includes branch, discipline, range, unit, resolution, calibration status/expiry, certificate reference and approved method IDs. Selection requires the same branch, compatible method, full range coverage and a valid calibration date.

Production needs a controlled standards register, document evidence, expiry reminders, out-of-service and quarantine controls, change approval, uncertainty linkage and immutable usage history. A standard used by a completed job must remain historically resolvable even after later revisions or retirement.
