# Executive and Owner dashboard

The Company Owner dashboard provides permission-controlled operational oversight without exposing unnecessary customer or protected pricing data. It includes RFQ/order counts, ageing, stage duration in days and hours, status/branch/representative performance, emergency/delayed/on-hold records, quote-to-order and loss ratios, monthly representative order value where a verified quotation total exists, new-client growth, recent activity and archive totals.

All South African commercial values use `en-ZA` Rand formatting. Protected quotation totals require explicit permission and record coverage is reported rather than estimated. Owner and Sales Manager PDF exports allow authorised date/month scope and selectable sections; representative and branch restrictions remain enforced.

At desktop and presentation widths, metrics, filters, tables and report controls wrap or reflow without clipping. Light and Dark modes use semantic text/surface pairs. The Executive Workflow Demo may switch among fabricated role perspectives, but production excludes this switcher and all demo identities.
