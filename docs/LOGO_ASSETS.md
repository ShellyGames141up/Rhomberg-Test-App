# Rhomberg Connect logo assets

The supplied raster reference was tightly recomposed, sharpened and separated from its textured rectangular background. The exact gauge/R concept and `RHOMBERG CONNECT` wording were preserved. Transparent edges and a consistent safe area allow the mark to sit naturally on app surfaces.

| Asset | Intended use |
|---|---|
| `rhomberg-connect-logo-master-transparent.png` | High-resolution transparent master |
| `rhomberg-connect-logo-full-light.png` | Full lockup on light surfaces |
| `rhomberg-connect-logo-full-dark.png` | Contrast-adjusted full lockup on dark surfaces |
| `rhomberg-connect-logo-compact.png` | Mobile and narrow headers |
| `rhomberg-connect-symbol.png` | Gauge/R symbol-only mark |
| `rhomberg-connect-logo-splash.png` | Startup and first-login presentation |
| `rhomberg-connect-logo-loading.png` | Loading panel |
| `rhomberg-connect-logo-email.png` | Future approved email/document headers |
| `rhomberg-connect-logo-monochrome.png` | Single-colour fallback |
| `rhomberg-connect-icon-512.png` / `-192.png` | PWA and packaging icons |
| `favicon.ico` | Browser favicon |

Large assets are referenced only by splash/presentation surfaces. Operational headers use compact assets. CSS uses `object-fit: contain` and never distorts proportions.
