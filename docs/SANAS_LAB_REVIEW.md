# SANAS Laboratory review — local correction

This correction preserves the approved manager-only, certificate-upload launch scope. It does not introduce technician worksheets or declare the deployed RHOMAPP release fixed.

## Confirmed defects corrected

- Backend physical-unit IDs differed from those generated by the shared Laboratory screen. New IDs now agree; already persisted certificate IDs remain unchanged.
- The SQL queue selected only old technician workflow stages. Certificate preparation now includes configured certificate orders outside those stages and retains completed certificate history.
- A failed second upload could leave the first upload saved. All entries are validated first; document metadata, unit changes, notifications and audit inserts now share one database transaction. Stored files are removed on failure.
- Concurrent repeated uploads cannot issue two current certificates for a unit. Replacement checks the current certificate under the order lock, preserves prior versions and records the replacement reason in audit history.
- Replacement metadata now records document version and predecessor links. Invalid calendar dates, mismatched certificate types and repeated units/numbers within a batch are rejected.
- Incomplete certificate tasks cannot be archived. Completing certificates updates the task's completed state, without pretending that physical fulfilment has completed.
- Customer order payloads exclude internal Laboratory notes and replacement reasons. Certificate endpoints reject other document kinds. Customers cannot download superseded certificates through either certificate or generic order-document routes.
- Pending customer downloads remain quarantined; failed/rejected files cannot be downloaded by staff either. No malware-scanning bypass was added.
- The manager detail screen now offers an audited current-certificate download. Success wording no longer claims customer downloads are immediately available before scanning.
- Customer and assigned Representative receive certificate notifications and a safe timeline event. Missing recipient addresses are shown as missing, not invented as an approved address.
