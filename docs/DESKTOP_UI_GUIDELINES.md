# Desktop UI guidelines

Internal operational screens use one responsive codebase with desktop workspaces, not enlarged mobile cards.

- Bound workspace width on laptops, 1080p, 1440p and ultrawide displays.
- Use dense queue rows/tables, aligned search/filter controls and multi-column details.
- Keep toolbar/filter controls visible where useful; do not obscure content.
- Use 14–16 px body text, strong hierarchy and comfortable line height.
- Keep primary actions aligned with the department workflow and separate destructive/override actions.
- Allow horizontal data density only where responsive cards provide a smaller-screen fallback.
- Use consistent surfaces, navy/cyan industrial colour, keyboard-visible focus and readable dark theme.
- Respect reduced-motion preferences.
- Keep empty/loading/error states informative and user friendly.

Laboratory and QA are desktop-only preview roles. Sales, Management, Planning, Expediting and Dispatch retain their established visual design but use bounded, denser desktop layouts. Browser QA should cover approximately 1366×768, 1920×1080, 2560×1440 and an ultrawide viewport.
