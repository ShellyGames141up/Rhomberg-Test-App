# Rhomberg Connect brand guidelines

Rhomberg Connect uses one protected visual system across customer, Sales, Technical, operational and Executive Demo experiences. Users may choose Light, Dark or System mode and approved accessibility display options; they cannot replace brand colours, upload a company application logo or create a custom palette.

## Official palette

| Purpose | Colour |
|---|---|
| Deep navy | `#021f31` |
| Technical navy | `#053f58` |
| Cool blue | `#087aa0` |
| Electric cyan | `#31d3df` |
| Bright teal | `#10a9bd` |
| Charcoal text | `#102f3d` |
| Success | `#217a55` |
| Warning | `#98630f` |
| Error | `#a93042` |

Glow is limited to startup, welcome, focus and important-loading moments. Body text always uses semantic foreground tokens rather than glow or brand accent colours.

## Usage

- Use the full logo for splash, login, desktop headers and formal presentation surfaces.
- Use the compact logo in constrained mobile headers.
- Use the gauge/R symbol for application icons, favicons and small loading moments.
- Preserve transparent safe area and aspect ratio. Never stretch, skew or place the master in a screenshot-like black rectangle.
- Use the monochrome fallback where colour output is unavailable.
