# Laboratory signature workflow

1. Generate the final unsigned PDF from approved immutable data.
2. Download through an audited, authorised action.
3. Apply the signature only in Rhomberg's approved external signing tool.
4. Re-upload the unchanged signed PDF.
5. Verify PDF type, certificate number, issue date, malware result and digital-signature trust on the future backend.
6. Store the file in write-protected object storage, record SHA-256 and create a certificate version.
7. A technical signatory or permitted manager releases it to the selected recipients.

No signing keys, passwords or credentials are stored in this repository or mock browser. Replacement requires a reason and preserves the superseded version.
